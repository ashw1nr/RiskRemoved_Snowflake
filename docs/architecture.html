D

Design Decisions (Gaps 1-9)

Gap 1: Transaction Grain Conversion

Decided: Each AMLworld pair row becomes two leg rows: one debit (negative amount), one credit (positive amount), sharing a txn_pair_id. Pair-level view for graph queries via self-join.

Gap 2: SCD2 on DIM_PARTY

Future scope. DT_DIM_PARTY is current-state only. No effective_from/effective_to. Columns removed from DDL. SCD2 is a "What Production Would Need" slide item.

Gap 3: Sanctions Screening

Decided: Exact join only. DT_SIGNALS_FAST does exact/near-exact name join against DT_SANCTIONS_CONSOLIDATED. CORTEX_SEARCH_BATCH fuzzy screening and SCREENING_RESULT table dropped. Fuzzy matching is future scope.

Gap 4: Case Deduplication

Decided: "Existing" = CASE with status IN (OPEN, INVESTIGATING, DRAFTED) for same party_id. Multiple signals in same refresh attach to same case. Different signal types merge into case_type = 'CROSS_DOMAIN'.

Gap 5: Evidence Pointer Resolution

Decided: Separate query log table. EVIDENCE stays clean (ref_type, ref_id, as_of_ts). EVIDENCE_QUERY_LOG stores sql_text, result_hash, query_id, executed_at — linked via FK. Reviewer re-runs SQL with AT(TIMESTAMP => as_of_ts) and compares hashes. RESULT_SCAN not used.

Gap 6: STR XML Generation

Decided: generate_str_xml() is a Python stored procedure. Reads FINDING + EVIDENCE for structured fields via SQL. Takes narrative from FINDING.narrative as-is. Assembles with xml.etree. Validates against schema. LLM never touches XML.

Gap 7: Verified Query Inventory

Planned (roadmap): 20 verified queries across 8 categories: transaction lookup (1-3), velocity (4-6), threshold (7-9), network (10-12), sanctions (13-15), cross-silo (16-17), case status (18-19), refusal (20).

Gap 8: RLS Roles

Decided: Two roles: BRANCH_ANALYST_MUMBAI (branch_region = MUMBAI only) and COMPLIANCE_OFFICER (sees all). RLS on DT_TRANSACTIONS_ENRICHED + DT_DIM_PARTY. Masking on PAN/Aadhaar fields.

Gap 9: Replay Harness

Decided: Simplified. Python script using snowflake-connector-python, INSERT INTO batches, time.sleep(). --inject structuring_burst flag. No Snowpipe Streaming SDK.
